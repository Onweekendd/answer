# 替用户做花钱之前的功课

用户要的是**能让他自己做决定的材料**，不是替他拍板。功课做得好不好，看三点：查到了他自己一晚上也拼不出来的信息；每条都有出处；把他该问商家的问题列出来。

## 1. 先判断这笔钱买的是什么

| 类型 | 例子 | 去哪查 |
|---|---|---|
| 商品 | 显示器、扫地机、手机 | 小红书看口碑，淘宝、京东看价格 |
| 培训、课程、证书 | 职业培训、考证、留学中介 | 秘塔核实资质和官方说法，小红书看学员的真实经历。**不要去淘宝、闲鱼搜**：搜出来的是网课和网盘资料，和线下培训不可比 |
| 服务 | 装修施工、家政、维修 | 小红书看真实经历和避坑；涉及资质、合同、收费标准的用秘塔核实 |
| 出行、体验 | 旅行、酒店、门票 | 小红书看攻略和真实体验，平台查价格 |

## 2. 三类信息，三个地方

- **真实的人的经验**（值不值、踩过什么坑、学完能不能用上）：小红书，先读 site-guide 里小红书的那篇 reference（xiaohongshu.md）。读两三篇有代表性的就够了：一篇说好的、一篇吐槽的，评论区往往比正文有用。
- **要核实的说法**（「国家认证」「官方授权」「持证上岗」、政策、行业标准、机构背景）：秘塔，先读 site-guide 里秘塔的那篇 reference（metaso.md）。**秘塔的回答只是线索**：同一个问题问两次，它的说法可能相反（2026-10-21 实测过）。结论以它列出的来源原文为准，优先看政府网站（gov.cn）、协会官网。
- **价格**：商品去电商平台，出行去平台；培训、服务的价格只能来自用户给的报价和小红书上别人自述的价格，要说明是自述、没法核实。

商家说的话（「国家认证」「包就业」「名额有限」）一律当作待核实的说法，不要当作事实写进回答。

## 3. 金额大、有几条路可选时，算一笔账

比如驾校「VIP 班 6800 / 普通班 3800 / 退报名费扣 500」。把每条路的总花费（含没写进报价的考试费、证书费、复训费）、要花的时间、已经花掉退不回来的钱列清楚。有工作台就用 python 算并列成表；没有就在回答里写清楚算式。不要替用户选，只把账摆出来。

## 4. 省步数

一次任务的步数有限。大致这样分配：

- 秘塔：问 1 次，点开 1～2 个最权威的来源读原文
- 小红书：搜 1～2 个词，读 2～3 篇
- 价格：只在真需要比价的时候查 1 个平台

查不到就停，在回答里说没查到，不要换着网站反复试。

## 5. 回答怎么写

- 先用一两句话说最关键的发现：往往不是「贵不贵」，而是用户没意识到的那件事（比如这个证书的门槛、这个行业的现状）。
- 再分几条写依据，每条后面附上出处的网址：官网原文、小红书笔记（点开笔记后结果里的那个 /explore/… 网址）。秘塔只是帮你找到原文的工具，出处写原文的网址，不写秘塔的网址。
- 把用户该去问商家的问题列出来，比如「证书全称是什么？是哪个部门发的？能在哪个官网查到？」。
- 哪些说法没核实到，直接写没核实到。

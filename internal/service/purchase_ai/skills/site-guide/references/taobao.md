# 淘宝、天猫

2026-10-18 实测，商品详情那部分 2026-10-19 实测。网站改版以后可能不准：照着做不成功时，以页面实际为准。

## 搜索

- 首页 https://www.taobao.com ，搜索框是 `<input id=q name=q>`：type 填关键词，submit 填 true。
- 搜索结果会在**新标签页**里打开，会自动切换过去，接着 snapshot 就行。
- 也可以直接 open 或 navigate 到 `https://s.taobao.com/search?q=关键词`。

## 排序和筛选

排序栏在快照里是选项卡：`<li role=tab aria-selected=…>`，依次是综合、销量、价格、区间。

- **按销量排序**：click "销量"。网址**不会**变；重新 snapshot，看到 `aria-selected=true>销量` 就是生效了。不要自己拼 `sort=` 之类的网址参数代替点击，拼出来的网址不一定生效。
- **按价格排序**："价格"要 hover 才展开菜单。hover 它，再 snapshot，会出现"从低到高""从高到低"，click 其中一个。
- **价格区间**："区间"也要 hover 展开。展开以后快照里有"¥ 最低价""¥ 最高价"两个输入框、几个预设区间，以及"重置""确定"。填完最低价和最高价以后**必须 click"确定"**，按回车不会提交。（"确定"点下去之后列表会不会刷新，还没实测过。）

## 商品卡片

- 每个商品是一个带 `id=item_id_数字` 的链接，文字里有标题、价格（比如 `¥ 5499 国补后`）、收货人数、地区、店铺。卡片最下面标着店铺类型，比如"品牌旗舰 无印良品旗舰店"。
- **列表上的价格不能直接当答案**：
  - 它是最便宜那个规格的价：被子分 150×200、200×230，手机分 128G、256G，价格能差好几倍；
  - "补贴后""券后"要满足条件才有；
  - 有的价格干脆显示成 `¥ 2??`、`¥ 5???`（淘宝把补贴价藏起来了）。
  所以列表只用来挑商品，价格要进详情页看。

## 优先看官方旗舰店

- 用户要的是某个品牌的东西时，**先找官方旗舰店的同款**：卡片上标着"品牌旗舰""官方旗舰店"，或者店铺名是"品牌名 + 旗舰店"的。正品有保证，它的价格也是比较别家的基准。
- 直接在搜索结果里挑带这个标签的卡片点进去，**不要先进店铺首页再在店里搜**：多打开两三个页面，更容易被风控拦住。只有搜索结果里找不到这个型号时，才去店里搜。
- 看完旗舰店，再挑一两家价格明显更低的看看（比如天猫超市、百亿补贴），说清楚便宜在哪、有没有条件。

## 商品详情

2026-10-19 在天猫（无印良品MUJI官方旗舰店）实测。

- click 卡片，详情页（detail.tmall.com、item.taobao.com）在**新标签页**里打开，会自动切过去。
- **一进来先 read**，一次就能读到大部分要的东西：
  - 店铺名和评分（比如"无印良品MUJI官方旗舰店 4.9"），据此确认是不是官方旗舰店；
  - "参数信息"：材质、含绒量、羽绒种类、货号，还有这个商品**所有的规格**（比如"尺寸 150x200cm 200X230cm 220x240cm"）；
  - 价格、已售多少、发货和运费；
  - "用户评价"的标签（"没有异味18""保暖性好16"）和两三条评价，"问大家"的两三个问答。
- **规格可以选**：快照里每个选项一行，写着组名和选项，比如 `[16]<div>颜色分类：芥末黄色`，选中的那个后面有"（已选）"，没货的有"（无货）"（2026-10-19 实测）。页面上的价格是"（已选）"那个规格的价。用户要的规格没选中时，click 那个选项，再 read 看价格：（已选）和价格都会跟着变，网址里的 skuId 也跟着变（2026-10-19 实测无印良品懒人沙发：沙发本体 ¥598、芥末黄色 ¥796）。用 pick_product 记商品时，链接会带上这个 skuId，用户点开就是这个规格。
- 天猫换规格不会打开新页面，不像京东那样每换一次都算打开一次（2026-10-19 连换两次没有被拦）。但也只换用户要的那一两个规格，不要挨个点。
- read 读到的价格区是这样的，"￥"和数字各占一行：`平台加补后 / ￥ / 473 / 明晚 8点开卖 / ￥ / 598 / 领消费券后约¥448 / 官方立减15%省90元`。意思是：原价 598；平台补贴后 473，要等到写着的时间（"明晚 8点开卖"）才有；领消费券以后约 448。回答里几个价都写上，说清楚各自的条件。
- 快照里一长串没有文字的 `<a>` 是图片链接，不是规格，不要去点。
- **藏起来的价**：有的商品的补贴价是完整显示的（上面那个沙发），有的写着"平台加补后 ￥4??"和"手淘查看完整优惠"，补贴价只在手机淘宝里看得到。网页上能看到的另一个价（比如"￥588"）是不算补贴的价。回答里两个都写上，说明补贴价没法在网页上核实。
- 回答里写清楚：哪家店、什么规格、什么价，价格有没有条件（领券、满减、补贴、会员）。
- 页面最上面有登录账号的名字，不要写进回答。
- **一次任务最多打开 3 个详情页**（旗舰店 1 个，再加 1～2 个对比）：详情页比搜索页更容易触发风控。看完一个想看下一个，就 navigate 回搜索结果的网址。
- 只看，不买：不要点"立即购买""加入购物车""领券"。

## 风控

淘宝的风控很严。短时间里反复打开搜索页，会弹出"访问太频繁，请稍后重试"的提示。它是另一个域名的 iframe，快照里看不到，点击会报"被遮挡，盖在上面的是 iframe，来自 h5api.m.taobao.com…punish"。

出现这个提示以后，整个账号会被拦一段时间，换标签页、换网址都没用。**看到它就停下**：调用 done，success 填 false，说明被淘宝拦住了，建议过一会儿再试。平时也要少打开页面：一次搜索能看到的，就不要重新搜。

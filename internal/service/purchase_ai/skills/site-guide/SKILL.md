# 在常用网站上查资料

每个网站的常见操作写在 references 里，都是实测过的做法。**打开某个网站之前，先用 skill_read 读它的 reference**，照着做能少走很多弯路。没有 reference 的网站，按通用做法来。

| 网站 | reference | 什么时候读 |
|---|---|---|
| 京东 | references/jd.md | 查京东的价格、自营还是第三方、看商品详情时 |
| 淘宝、天猫 | references/taobao.md | 查价格、销量、旗舰店同款，要在淘宝搜索、排序、筛选价格区间、看商品详情时 |
| 1688 | references/1688.md | 查批发价、工厂货、起批量时 |
| 闲鱼 | references/goofish.md | 查二手价格、成色时 |
| 小红书 | references/xiaohongshu.md | 看用户的使用体验、口碑、避坑经验时 |
| 宜家 | references/ikea.md | 查宜家商品的价格、尺寸、填充物和材料时 |
| 秘塔 AI 搜索 | references/metaso.md | 核实资质、认证、政策、机构背景这类说法，找政府网站、协会官网的原文时 |

## 通用做法

- 先 snapshot 看页面上能操作什么，再动手；页面变了就重新 snapshot，编号只在最新一份快照里有效。
- 快照只列能点、能填的东西，普通的段落文字（文章正文、评论）不在里面；要读这些用 read。文字在图片里的，才用截图。
- 一组可以左右翻的图（轮播图），用 press ArrowRight / ArrowLeft 翻页，翻完截图看。
- 有的网站首页的搜索框是个"假框"，点了才弹出真正的搜索层（宜家就是这样）：在假框里输入、回车，页面没反应。先 click 搜索框，再 snapshot，往新出现的那个输入框里 type。
- 步数有限，一步里可以同时调用好几个工具。不改变页面的（skill_read、snapshot、read、screenshot、方向键）放在一起；会改变页面的（open、navigate、click、回车、Escape）放在最后，它后面的调用会被跳过。
- 能在一个页面上查完的，不要反复重新打开、重新搜索：打开页面的次数越多，越容易被网站拦住。
- 页面上弹出广告、优惠券这类弹窗时，快照最后会说"页面中间开着一个浮层"，能认出关闭按钮的话，快照里有一行"关闭弹窗"，click 它；没有就 press Escape。不要点弹窗上的"立即使用""领取""去看看"。
- 点击报"被遮挡"时，看报错里说盖在上面的是什么：普通弹窗、浮层就照上一条关掉；验证码、登录、"访问太频繁"这类提示就停下，在回答里说明。
- **在详情页上看中了就当场 pick_product**，看完一个记一个。不要等全看完了再回头一个个重新打开：每打开一次页面都要花步数，也更容易被拦。

# browser-use 源码学习笔记

读的是 `browser-use/`（本地克隆，已在 .gitignore 里），版本 `c75e8476e`（2026-10-07）。

目的不是学会用 browser-use，而是搞清楚一个通用浏览器 Agent 是怎么搭起来的，然后用 Chrome 插件 + Go 做我们自己的版本。

## 先记住一个大前提

browser-use 是 **Python 程序通过 CDP 远程控制 Chrome**，不是浏览器插件。

打个比方：browser-use 像**坐在监控室里的遥控员**，通过 CDP 这根"遥控线"，能看到浏览器内部的一切（每个节点的 ID、谁画在谁上面、哪个元素挂了点击事件），也能直接"按鼠标"。我们的插件则像**派进页面里的卧底**（content script），人就在现场，能直接摸 DOM，但看不到浏览器内部的某些"后台数据"。

所以读每一站都要问自己：**这一步换成插件，我能怎么做？** 每份笔记最后都有一节专门回答这个问题。
